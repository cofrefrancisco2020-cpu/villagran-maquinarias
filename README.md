# Villagrán Maquinarias y Equipos — versión 1

Página estática de catálogo para arriendo de maquinaria en Pucón.

## Abrir y publicar

Abrir `index.html` directamente o servir esta carpeta como sitio estático. Para Vercel, configurar la carpeta `version 1` como raíz del proyecto y usar **Other** sin comando de build ni carpeta de salida. También se puede subir el contenido de esta carpeta a la raíz de un repositorio.

## Archivos

- `index.html`: contenido, catálogo, enlaces y metadatos.
- `styles.css`: diseño adaptable, colores y animaciones.
- `script.js`: filtros, búsqueda, menú y consultas con equipo precargado en WhatsApp.
- `assets/`: logo público y fotografías ilustrativas generadas para cada tipo de equipo.
- `brief-marca.md`: fuentes, decisiones y límites de la información.

Las imágenes de maquinaria son ilustrativas y no representan modelos, marcas ni inventario exacto. Confirmar disponibilidad, valores, plazos y condiciones directamente con la empresa. El logo proviene del perfil público de Facebook; para una futura versión puede reemplazarse con el original de alta resolución.

## Actualizaciones

Duplicar esta carpeta como `version 2` antes de hacer cambios. Mantener las imágenes finales en `assets/` sin subcarpetas.
